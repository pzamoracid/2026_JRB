Antes de cerrar una guía: descarga tu respaldo JSON

Las guías realizan autoguardado local en el navegador mientras trabajas. Para continuar de forma segura en otra clase, especialmente si puedes cambiar de computadora o navegador, debes conservar un respaldo propio.

  1. Antes de cerrar la guía, pulsa Descargar respaldo JSON.
  2. Guarda el archivo .json en un lugar seguro donde puedas encontrarlo en la siguiente clase.
  3. Cuando regreses, abre la misma guía y selecciona Cargar respaldo JSON.
  4. Continúa trabajando y vuelve a descargar un respaldo actualizado antes de salir.

Nota: el navegador puede conservar el autoguardado en el mismo equipo, pero no se garantiza si cambias de computadora o navegador, utilizas navegación privada, se borran los datos del sitio o el equipo es restaurado. El archivo JSON es el respaldo que debes conservar.
