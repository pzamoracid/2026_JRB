Propósito

Aplicarás herramientas de edición fotográfica en Photopea para crear una composición visual relacionada con el mBot2. Trabajarás con capas, efectos, texto y exportación de archivos.

La actividad es común para las tres orientaciones y mantiene al mBot2 como elemento tecnológico central.
Importante: las fotografías o capturas que agregues son opcionales y no afectan la condición de COMPLETO/PENDIENTE. La revisión de completitud no representa una calificación automática.

Actividad 2 — Práctica guiada: fotomontaje del mBot2

Abre Photopea y desarrolla la práctica siguiendo esta secuencia.

Crea el proyecto. Usa un lienzo de 1280 × 720 px y coloca un nombre identificable al archivo.
Incorpora las imágenes. Utiliza Archivo → Abrir y colocar para agregar fondo, mBot2 y caja/presentación del mBot2. Conserva cada elemento en una capa independiente.
Organiza la composición. Usa Mover (V) para acomodar los elementos y mantener al robot como elemento principal.
Aplica efectos de capa. Experimenta con Trazo, Sombra interior y Sombra paralela sin saturar el diseño.
Agrega texto. Usa Texto (T) para escribir un título, por ejemplo: Conoce al mBot2.
