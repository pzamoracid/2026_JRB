Actividad 1. Planteo el caso técnico

Caso: una computadora indica que está conectada a la red, pero el usuario informa que no puede acceder correctamente a Internet. Antes de cambiar configuraciones, debes reunir información y comprobar cada punto de la conexión.

Actividad 2. Reviso la configuración IP

En Windows abre Símbolo del sistema y ejecuta:

ipconfig /all

No cambies ninguna configuración. Solo observa y registra los datos necesarios.

Agrega una captura donde puedan verificarse los datos utilizados. Evita incluir información personal que no sea necesaria.

Actividad 3. Compruebo la ruta de conexión

Realiza las comprobaciones en orden. Si el docente indica otros valores para la red del laboratorio, utiliza esos valores.

A. Prueba local

ping 127.0.0.1

B. Puerta de enlace

ping [dirección de la puerta de enlace]

C. Acceso por dirección IP

ping 8.8.8.8

Un equipo o servicio puede estar configurado para no responder a ping. Por eso un resultado negativo no demuestra por sí solo cuál es la falla; debe interpretarse junto con las demás pruebas.

Comenta debajo de cada captura qué prueba realizaste y cuál fue el resultado.

Actividad 4. Compruebo la resolución de nombres

Ejecuta una consulta DNS:

nslookup www.google.com

Incluye el comando y el resultado que utilizaste para tu conclusión.
